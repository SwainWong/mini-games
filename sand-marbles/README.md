# 沙里有珠 · 15 关地下奇遇

原生 HTML / Canvas 挖沙小游戏。按住鼠标或手指挖通沙土，把全部珠子送入同色罐子。错色入罐或漏接需要重玩。

## 评分

- 只有通关才给星：挖沙量不超过本关三星额度为 3 星，不超过二星额度为 2 星，其余通关为 1 星。未完成和失败均为 0 星。
- 只统计玩家实际挖掉的沙。重复划空洞、挖石块、预设通道和蚯蚓挖掘不计分。地震回填后重新挖掘会计入。
- 以固定 560 × 680 逻辑画布上的挖掘面积计量（100 平方逻辑像素 = 1 沙量，向上取整），不受屏幕分辨率影响。
- 每关有独立额度：用常规铲沿参考解法计算需要挖的沙，三星额度为其 1.10 倍，二星为 1.60 倍，向上取整。参考解法并非声称数学最优解。
- 不计用时，提示不扣星。每次尝试独立评分，关卡选择展示本次页面内的最佳星级。刷新全部重置。

## 机关与操作

- 蚯蚓沿固定的可观察轨迹挖掘，改变通道。它挖的沙不计入玩家用量。
- 地震从第一铲开始计时，第 6、14 秒各发生一次；抖动珠子，并在标示虚线框内少量回填。回填避开活跃珠子周围，不会直接把珠子埋住。
- 风口按箭头方向侧吹；轻盈珠受影响更大。
- 黏土区域降低速度，仍可通过。
- 闸门定时开合，珠子可停在门上等待。
- 磁石仅吸引重力珠。
- 有精细（半径 14）、常规（24）、宽铲（34）三档。提示可显示参考解法，建议从罐口向上挖，最后连接起点。
- 打开玩法说明、选关面板或切换到后台时暂停模拟。选关会开始新的尝试。

## 声音与画面

右上角音效开关默认关闭，由点击手势解锁 Web Audio。合成挖沙、碰撞、入罐、蚯蚓、闸门、地震、胜负音效；关闭后立即停止声音，不依赖外部音频文件。

沙土颗粒、玻璃、金属/橡胶纹路和机关均由 Canvas 绘制，动态地形与碰撞网格一致。未使用生成式贴图，避免重复纹理、加载依赖和画面边界与物理脱节。

## 代码与验证

- `core.js`：可在浏览器和 Node 共用的地形、计分、物理与机关逻辑。
- `levels.js`：全部关卡、参考路径、起点和机关配置。
- `game.js`：绘制、输入、HUD、选关与评分结果。
- `audio.js`：本地音效合成。
- `tests/`：计分边界、地形计数、机关行为、15 关参考解法的真实物理测试与浏览器操作脚本。

运行 `node --test sand-marbles/tests/*.test.cjs`。浏览器验证脚本 `tests/browser-check.js` 是 Playwright CLI 的 `run-code` 函数，支持 URL 参数 `verifyFrom` / `verifyTo` 分批验证；它只使用真实鼠标拖动，不修改物理状态或直接设置通关。

运行时没有后端、账号、遥测或持久化存储。刷新回到第 1 关、0 挖沙量、无星级记录、默认静音。独立入口为 `index.html`，资源都在本目录，左上角返回合集主页。
