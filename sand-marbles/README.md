# 沙里有珠 · 搬罐奇遇

纯 HTML / CSS / JavaScript Canvas 游戏。十五张独立设计的地图，划开沙土，让珠子经过同色接珠盘装入罐子。

## 星级与状态

- 只有全部珠子实际装罐才通关；失败、进行中没有星。
- 根据各关显示的挖沙额度评 1～3 星。只计算玩家新挖掉的沙；重复经过空洞、石块、蚯蚓挖掘不计费；用时不计分。
- 沙量为固定 560 × 760 逻辑画布中挖掘面积 / 100，向上取整。地形区域高度 564，底部是接珠盘和搬运区。
- 关卡随时可选，本次页面内保留最高星级。刷新回到第一关并清空进度、关闭音效。没有后端、存储、账户或分析请求。
- 三档铲子：精细半径 14、常规 24、宽铲 34。没有提示按钮、默认解法线或运行时解法接口。

## 两位邻居

- **蚯蚓**沿可观察轨迹不断挖洞，影响邻近沙路。
- **搬罐小哥**从第三关出现，随机选一个罐子。抱起 → 加减速碎步 → 放低喘气 → 再走 → 歇息 → 分段返程 → 原位停留。每一轮尽量换罐；罐子始终留在画布内且不与相邻罐重叠。
- 罐子离位时，原位的同色接珠盘暂存珠子并显示数量。罐子回到盘下才装入，等待期间不增加收集数，也不会提前通关。接错颜色或错过接珠盘仍失败。
- 已移除地震、风口、黏土、闸门和磁石，包括物理、绘制、声音和说明。

四种珠子继续保留：玻璃珠、带十字纹且更重更大的重力珠、回弹较强的环纹弹力珠、缓慢下落的菱形纹轻盈珠。

## 图像和声音

沙土、石块、珠子、罐子和搬运工均由 Canvas 绘制。人物包含大靴子、吃力姿势、汗滴和喘气气泡。无需外部贴图或图片服务。

音效默认关闭，由用户按钮开启 Web Audio；挖沙、碰撞、装罐、胜负、蚯蚓、脚步和喘气均本地合成。关闭立即停止当前发声，不在后台继续播放。

## 验证

```sh
node --test sand-marbles/tests/*.test.cjs
python3 -m http.server 4192 --bind 127.0.0.1
```

`core.test.cjs` 检查评分和挖沙计量；`mechanics.test.cjs` 检查搬运、暂存、公平性；`levels.test.cjs` 用实际物理执行十五关解法和多组随机搬罐种子。浏览器脚本通过真实鼠标/触屏输入检查通关，不调用自动获胜接口。

运行浏览器关卡回归前，将 `browser-check.js` 的 `/* SOLUTIONS */ null` 替换为 `JSON.stringify(require('./tests/solutions.cjs'))`，写到忽略的 `output/` 中，再交给 Playwright CLI 的 `run-code`。脚本支持 URL 参数 `verifyFrom` / `verifyTo` 选择验证范围。
