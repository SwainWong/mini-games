# 沙里有珠 · 积分矿场（v16 开发版）

纯 HTML / CSS / Canvas / Web Audio，十五关，无后端、账户、遥测或持久存储。刷新重置关卡、图鉴、成绩和声音。详细持续演进方案见 [设计文档](../docs/superpowers/specs/2026-09-18-sand-score-adventure-design.md)，包括全部十五关分值、机制引入、地图物件、结算优先级和后续平衡约束。

## 得分与过关

普通同色珠子落入完整且有容量的矿车 +10，灰裂废珠 +3；问号袋可能 +20、+40、小炸弹或全沙回填，宝箱固定 +30。错色、漏接、被偷只让这颗珠子成为 0 分，不扣已有分数。目标是过关门槛，不是分数上限；达标继续冲分。关卡时间耗尽或全部珠子结算时，按最终分数是否达到门槛决定胜负；「已有分数 + 剩余最高可得 < 目标」时提前失败。剩余最高可得是理论上限，不是对实际路线可达性的保证。宝物只由珠子碰开，每件一次，珠子继续运动。上限包含仍有机会超载漏出的袋内珠子；既没有活跃珠子、也没有可追回珠子时，未开的宝物不再计入上限。

只有通关才评星：新增玩家挖沙量不超过三星预算得3星，不超过二星预算得2星，否则1星。失败没有星。机关挖沙免费，空洞不重复计费；用时不计分。单一铲子半径20，沙量按逻辑面积/100向上取整。没有无限提示或默认路线。显示关卡剩余时间，暂停不扣时间；第1—15关分别为45、45、50、50、50、55、55、60、60、60、65、65、70、70、75秒。

## 元素与真实交互

- **盗宝人**从第二关出现，基础挖速30/34/38，空道1.65倍；体力满时快、疲劳时慢，低体力屈膝坐下、擦汗、喝水，恢复后起身；使用12张完整休息姿势。快速珠子靠近会触发侧耳与短冲刺，反应有冷却；伸手0.28秒、抱起0.32秒、装袋0.4秒；完成才算偷走。袋子随真实颗数变大，负重增加耗体力、降低移动速度。超过6颗后每移动1秒有5%概率破袋，破袋后每移动0.75秒漏出原珠子，可重新接回。落石使其眩晕4秒，期间不能移动、挖掘或偷珠。静音不影响听觉AI。190像素内爆炸会让他受惊，近距离先踉跄0.35秒；50%概率弃袋逃跑、50%背袋逃跑。袋中原珠子可从弃袋掉出，带出屏幕后才算失去得分机会。
- **落石**按旋转椭圆底部支撑宽度与重心判断。偏侧支撑会倾斜滚落，薄土柱会被压碎；不显示落区投影。松动约0.55秒后开始运动，位移子步不超过2像素。旋转后的贴图、地形遮挡、珠子碰撞和炸药附着位置一致。落入矿车占用容量并随车移动，不砸坏车；满车珠子弹开或滑出。可以晕盗宝人、清除虫子。
- **引线炸药**从第八关出现，珠子先碰到岩石上游的压力盘点火，1.8秒引线后半径78爆炸。炸碎岩石、晕人、除虫，也可能炸坏车；珠子只受冲力。炸药随绑定石头移动，未点火时石头被毁则失效；燃烧中的炸药可连锁，每个只爆炸一次。全部含炸药关卡都可不点火通关。
- **钻沙虫**从第五关起2—4条，持续挖出真实岔路，岩石转向，被消灭后不再挖沙。
- **方向盘操作员**第三关开始，始终只有一名，背对玩家、面向矿区，在右下角方向盘台按随机轮次公平切换矿车。信号柱亮起的颜色与实际受控矿车一致；切换时伸手指车，另一只手握方向盘。每次爆炸都受惊、刹车0.9秒，35%概率逃岗；留下者恢复控制，逃岗者本局不返回，车斗仍可正常接珠。车辆连续加减速，到端点折返；切换目标前制动，避免反复走停。动作图集有24张完整人物帧（其中1张备用），包含11帧转向和左右抬手、指车、收手、重新握持；另有惊吓和逃跑。人物、轮盘、底座分层：底座固定，轮盘平滑旋转，每帧只绘制一个不透明人物，避免透明叠图产生残影。
- **单轨矿车**保持初始左右顺序，中心间距≥104，受驱动车可推动停下的车并向后传递碰撞，相向推挤/残骸/落石会挡住整列。密集四车最大偏移24像素、三车38像素。车体、车口、颜色牌始终一起移动，只有当前位置接珠。共享开口几何 y590、半宽46，以珠子中心跨越开口时的相对运动插值判定，车沿没有隐藏的珠子半径缩进。
- **图鉴**首次出现的元素必须确认，所有计时暂停；本次页面内只提示一次，重来不重复，直接选后关会补齐未见元素。常规图鉴可随时查看和关闭。关卡选择、图鉴、后台都暂停，恢复清空旧划线和积累时间。

四种材质：玻璃、重力、弹力、轻盈，分值相同，通过纹路区分物理行为。已移除地震、风口、黏土、闸门和磁石。

同一物理步先按接触时间排序；同一时刻按宝物、有效入车、伤害/眩晕、偷取/其他损失处理，整组后检查得分机会不足或珠子已全部结算。达标不会清空后续事件；时间截止的最后物理步会处理完所有有效接触后再结算。已得分不倒扣。

## 美术与声音

经典矿工游戏的暖棕土层、木金属边框、TARGET/SCORE布局，搭配原创生成2.5D角色。Image先生成新盗宝人六状态和道具图集，再接入游戏。全部提示词与尺寸在 [assets/README.md](assets/README.md)。运行时只加载本地素材，不调用生成服务。

挖土从实际挖除位置喷砂、扬尘，坑壁有厚度，土层有沉积纹。图鉴展示对应角色/道具。音效默认关闭，可自主打开；挖沙、宝物、引线、爆炸、眩晕、接珠等由Web Audio本地合成，关闭立即停声。

## 验证

```sh
node --test sand-marbles/tests/*.test.cjs
python3 -m http.server 4201 --bind 127.0.0.1
```

`levels.test.cjs`回放十五关×四种子；`bomb-routes.test.cjs`另外验证四个炸药关卡的可选/主动点火路线。测试只通过挖沙输入和物理推进，不直接赋分或停用机关。`cart-edge.test.cjs`包含不同材质、双沿、移动方向与速度的480个边界组合。`browser-cart-edge.js`使用真实鼠标/CDP触屏验证原先误判的车沿、外侧漏接、冻结、重来与刷新。

v8及以前的browser脚本保留作历史用例，其“全珠收齐”和首次弹窗假设不适用于v10；当前验收及限制见 [发布审核记录](../docs/reviews/sand-score-release.md)。运行时只暴露只读snapshot，没有自动通关或修改世界接口。
