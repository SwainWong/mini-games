# 沙里有珠 · 宝藏争夺战

纯 HTML / CSS / JavaScript Canvas 游戏。十五张独立设计的地图，划开沙土，让珠子直接落进正在移动的同色车斗开口。

## 星级与状态

- 只有全部珠子实际入车才通关；失败、进行中没有星。
- 根据各关显示的挖沙额度评 1～3 星。只计算玩家新挖掉的沙；重复经过空洞、石块、蚯蚓挖掘不计费；用时不计分。
- 沙量为固定 560 × 760 逻辑画布中挖掘面积 / 100，向上取整。地形区域高度 564，底部是矿车和搬运区。
- 关卡随时可选，本次页面内保留最高星级、最少通关沙量及总完成数。更少挖沙会显示改善量，较差重玩和失败不覆盖最佳记录。刷新回到第一关并清空进度、关闭音效。没有后端、存储、账户或分析请求。
- 三档铲子：精细半径 14、常规 24、宽铲 34。没有提示按钮、默认解法线或运行时解法接口。

## 地下冒险队

- **盗宝人**从第二关出现。素材加载完且关卡可见后立即开始，以 22/25/28 逻辑像素每秒的基础速度沿真实路线挖向未入车珠子，A* 绕开石头，已有通道内速度再乘 1.85，每 0.35 秒重新追踪目标。铲子实际够到任意珠子即失败，不按时间自动判负，不显示数字倒计时；接近时有距离警示、扬沙和可关闭的紧张音效。说明/选关弹窗、后台和结算时不推进；无需玩家先点击。不会抢车内珠子，其挖沙不计玩家沙量。
- **蚯蚓**从第五关起每关 2—4 条，以 41—57 逻辑像素/秒穿行，挖出半径 17 的真实岔道。每条有独立活动区域，碰到岩石转向，不会挖掉石块或永久卡在斜角。蚯蚓的真实位置与画面一致。
- **推车队友**从第三关出现。开局随机分配一辆矿车，本关持续操作它，避免在不同矿车间瞬移。每趟随机方向、步长、停歇和折返距离；有左右脚推行、拉车减速、擦汗、思考与接珠庆祝六帧。小角色在轨道前侧的地面行走，手掌逐帧锚定侧把手，不挡住相邻车斗。
- **矿车就是唯一接珠目标**：车身、车斗开口、颜色标签和收集数量一起移动。车轮沿矿轨滚动，车斗高度固定；每个物理步按珠子与移动开口的相对轨迹判定入车。旧位置没有接珠盘、隐形判定或暂存队列。错色或漏接失败；可以留一层沙，等矿车停下再放珠。失败后可查看冻结地图与实际失误位置。
- 已移除地震、风口、黏土、闸门和磁石，包括物理、绘制、声音和说明。

桌面采用插画工具侧栏，手机采用紧凑工具区、触控按钮和三列选关。连续六秒基本静止的珠子会显示停留数量，状态反馈不包含解法。

四种珠子继续保留：玻璃珠、带十字纹且更重更大的重力珠、回弹较强的环纹弹力珠、缓慢下落的菱形纹轻盈珠。

## 图像和声音

先用内置 Image 生成统一 2.5D 卡通贴图，再接入 Canvas。v8 使用新生成的六帧小矿工、六帧盗宝人和独立矿车；保留 v7 的岩石与蚯蚓。动作实测手掌位置，矿车按实际开口对齐接珠判定，盗宝人铲头与真实挖土坐标一致。素材和完整提示词见 `assets/README.md`。运行时不调用图片生成服务；全部素材就绪后自动开始，加载失败暂停并提供重试。

挖沙会喷出大小不一、可旋转并落回坑壁的砂砾，伴随短暂尘雾；坑壁有厚度阴影，露出的土层有沉积纹和碎石。粒子来自本次实际被挖掉的位置；划空洞不会重复喷沙。盗宝人与蚯蚓挖掘也在真实接触点喷土。砂砾/尘雾设有数量上限，坑壁按地形修改缓存，特效不改变接珠物理或评分。

音效默认关闭，由用户按钮开启 Web Audio；挖沙、碰撞、入车、胜负、蚯蚓、脚步和喘气均本地合成。关闭立即停止当前发声，不在后台继续播放。

## 验证

```sh
node --test sand-marbles/tests/*.test.cjs
python3 -m http.server 4192 --bind 127.0.0.1
```

`core.test.cjs` 检查评分和挖沙计量；`mechanics.test.cjs` 检查实时车斗开口接珠、旧位置漏接、固定轨面、错色及搬运行为；`levels.test.cjs` 用实际物理执行十五关解法和四组随机推车种子，测试专用 timing.cjs 记录放珠前等待时间，运行时不加载。浏览器脚本通过真实鼠标/触屏输入检查通关，不调用自动获胜接口。

运行浏览器关卡回归前，将 `tests/browser-check.js` 的 `/* SOLUTIONS */ null` 替换为 `JSON.stringify(require('./tests/solutions.cjs'))`，写到忽略的 `output/` 中，同时将 `/* TIMING */ null` 替换为 `JSON.stringify(require('./tests/timing.cjs'))`，再交给 Playwright CLI 的 `run-code`。`rival.test.cjs` 检查真实挖掘、抢夺、岩石、边缘目标、暂停和回合重置；`tests/browser-rival.js` 通过真实鼠标等待抢夺并以 CDP 触屏完成第二关，检查音效、暂停、失败和刷新。

`tests/browser-moving.js` 专门以真实触屏验证搬走目标、成功、漏接、重来、音效与刷新。脚本支持 URL 参数 `verifyFrom` / `verifyTo` 选择验证范围。

`pressure.test.cjs` 检查首个竞争关的实际威胁时间、蚯蚓挖穿真实路径及岩石转向、随机搬运状态和完整人物安全范围。

`tests/browser-minecart.js` 以真实鼠标验证自动开局、蚯蚓/盗宝人/矿车同时推进、喷沙、桌面通关、加载失败暂停及重试。v8 验证记录见 `../docs/sand-minecart-v8.md`。
