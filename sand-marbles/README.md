# 沙里有珠 · Sand & Marbles

使用 HTML、CSS 和原生 Canvas 实现的挖沙小游戏。

按住鼠标或手指划开沙土，让玻璃珠在重力作用下落入同色罐子。石块不可挖掘；错色入罐或漏接需要重玩。

三个关卡：

1. 初识沙径：22 颗珠子，接通两色通道。
2. 各走各的路：20 颗珠子，绕开石块。
3. 三色归途：32 颗珠子，三色分流。

支持提示、重玩、自由选关与可选音效。所有进度仅在当前页面的内存中，刷新会从第 1 关重新开始。音效默认关闭。

独立入口为 `index.html`；所有资源保存在本目录，不依赖其他游戏或外部资源。左上角可返回合集主页。

画面参考挖沙落珠游戏截图，沙土纹理、珠子、罐子与物理模拟均由代码绘制。`game.js` 中的 `levels` 定义关卡、石块、珠子、罐子及提示路线；新增或调整关卡时同步验证这些配置。
