# 国王消消乐

两个独立设计的消除疏导关卡。点击上下左右相邻的两个以上同色宝石，清除固定砖墙；落石在重力、斜坡、碰撞和摩擦下经过空洞进入底部出口。砖不补位，不使用后台或持久化。

## 关卡

| 关卡 | 拓扑 | 步数 | 排出目标 |
| --- | --- | --- | --- |
| 王室金库 | 右侧竖直通道，7组贯通 | 10 | 100 / 120 |
| 水晶密室 | 右侧斜梁阻挡，向左接驳绕行，8组贯通 | 12 | 125 / 150 |

开始按钮之前静止，前12秒护盾保护。护盾之后只因面前石头持续接触耗损，解除接触可恢复；无倒计时失败。步数耗尽会等至少3秒物理结算，无排出且接近静止时判失败，最迟10秒。过关剩3步得三星、1步得二星、其余一星。

- 鼠标/触屏：轻点砖组，拖动不会清砖。
- 键盘：聚焦画布，方向键选择、空格或Enter清砖。
- 玩法、选关弹窗会暂停；切换后台后需要主动继续。
- 提示亮出能接通出口的下一组，不替玩家操作。
- 音效默认关闭，WebAudio本地合成。
- 刷新回第一关，所有进度归零。

## 本地运行和验证

项目根目录运行 `python3 -m http.server 4188 --bind 127.0.0.1`，打开 `/king-match/`。

```sh
node --test king-match/tests/engine.test.cjs
node --test sand-marbles/tests/*.test.cjs
```

`tests/browser-check.js` 是供 Playwright CLI `run-code` 使用的真实鼠标/移动触摸验收脚本，覆盖两关通关、暂停、无效点击、刷新。运行前打开当前服务器的 `/king-match/`；截图写入被忽略的 `output/`。制作人另有独立探索试玩报告。

## 实现

- `levels.js`：两张固定砖图、矿石数、推荐输入序列。
- `engine.js`：1/120秒固定步长、空间桶圆形颗粒碰撞、静态墙/砖/斜坡碰撞、真实出口计数、接触耐久、胜败。人物是卡通动画，散料使用圆形碰撞近似，不是多边形工程仿真。
- `renderer.js`：生成PNG图集按源矩形绘制，矿石旋转、背景、碰撞表面和消除反馈。
- `game.js`：DOM状态、pointer/keyboard、暂停、关卡和结果流程。`kingGame.snapshot()`只读诊断，无设胜/改状态接口。
- `assets/PROVENANCE.md`：image生成资源来源。用户参考图和视频未发布。

所有路径相对，支持GitHub Pages的 `/mini-games/` 子路径。无运行时外部依赖、无遥测、无浏览器存储。
