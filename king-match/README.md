# 国王消消乐

交换相邻宝石，横向或纵向连成至少 3 颗才消除。现有宝石自动向下落，落稳后再次三连会连锁，不补新宝石。黄色石料从满仓上方经斜坡料口持续进入，疏通下方出口才能减轻国王盾前压力。**国王存活，且宝石清空或落稳连锁后已无有效三消交换，即胜利**，不以排出的金子数量计胜。

国王有 **100 HP**。真正碰到身后尖刺时扣 12 HP，持续接触每 0.8 秒再扣 12；实体止挡防止穿刺，离开即停止受伤，不自动回血。HP 归零会失败。

| 关卡 | 排流结构 | 上游供料上限/秒 | 宝石总数 | 三星交换次数 |
| --- | --- | --- | --- | --- |
| 王室金库 | 右侧料井与下方出口连通 | 80 | 56 | ≤ 8 |
| 水晶密室 | 右侧固定承重石台，向左绕行 | 85 | 52 | ≤ 8 |

供料能力受真实入口空位、可达空间及料口限制；画外待入库存不产生压力。固定石台不是宝石，不计入全清。下落、连锁和自动疏通结算完，且 HP>0、宝石清空或没有合法三消交换，即停止供料并救援成功，HP0 同帧优先判失败。交换次数只影响星级。

国王会随压力切换双手、单手与背肩支撑。前方安全持续确认后收起盾牌并叉腰观察，预测落石接近时重新举盾；盾的可见位置与实体同步变化。受刺使用完整缩身、抬腿和恢复帧。

实际受刺伤后 HP≤40 时，每次符合条件的伤害有 35% 概率触发 **高能推盾**，持续 2.2 秒、启动后冷却 8 秒、每局最多两次。盾牌施加更大的实际向外推力，不回血、不无敌、不自动消砖；随机源与棋盘、物理供料分开。

- 鼠标/触屏：点两颗相邻宝石或相邻拖动，无效交换弹回。键盘方向键选择，空格或 Enter 确认。
- 下落与连锁期间不接收交换、重排；石头继续流动。金子会支撑并阻碍下落砖，受挤后尝试向侧面滚出。夹阻落稳期间暂停危险时钟，不扣血、不消耗重排；右侧铰接挡板连续转动暂缓下料，上仓仍正常补入。挡板遇到没有空间的颗粒会暂停转动，落稳后逐步打开。有出口或可容纳颗粒的自然侧下通路时保留金子；只有上下宝石砖形成持续承压、无法自然脱困时才局部碎金。碎裂与正常排出分别计数，不把短暂慢流当堵塞。承重石台按格对齐，其上下宝石分段下落。
- 两次「重排」只改变落稳宝石的颜色，不补空、不移石台。候选盘须有经验证的全清解；未找到时保留棋盘与次数。无法有效交换的尾盘自动通关，不依赖剩余重排次数。
- 「提示」优先使用经过重力和连锁验证的全清路线，限额搜索未找到则提示一组合法三消；首次第一关提供一次交换示范高亮。
- 暂停、玩法/选关弹窗和后台状态停止模拟与扣血；重来和刷新重置 HP、盘面及颗粒。
- 音效默认关闭，Web Audio 本地合成。无登录、存储、遥测或外部运行依赖。

## 实现边界

- `match.js`：三消、重力、全连锁、全清搜索与经验证重排；四种宝石，无初始自动匹配。
- `clamp.js`：受重力约束的脱困搜索、逐颗压力链识别；乐观粗网格不把未找到精细通路误判为可碎金。
- `geometry.js`：完整厚斜坡多边形、砖和盾联合边界；金子贴图限制在圆形实体内。
- `engine.js`：1/120 秒固定步长，真实圆形颗粒与数值空间桶、动态盾牌、移动宝石碰撞体、HP冷却、出口守恒。落位绘制与碰撞使用同一 y，旧位置没有幽灵碰撞。
- `renderer.js`：image 生成 PNG、实际几何对应斜坡/石台/尖刺、原完整八帧步态加单手撑盾、背肩撑盾、受刺、收盾观察四组新全身动作、交换发光碎裂、下落、连锁、受伤红闪、高能推盾及浮字。
- 接触压力采用碰撞冲量、穿透修正及实际贴盾颗粒数的小游戏近似，并非工程级散料仿真；宝石轨道重力为受约束运动。
- `kingGame.snapshot()` 只读诊断含 HP、粒子守恒、仓体填充指标、真实压力、盾位置和下落阶段，不提供修改状态接口。
- `assets/PROVENANCE.md` 记录生成素材。原始用户参考图视频不发布。v1/v2 文档保留作历史，当前规则以本说明与 v8 审查记录为准。

所有路径相对，支持 GitHub Pages `/mini-games/` 子路径。
