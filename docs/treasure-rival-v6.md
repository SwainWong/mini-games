# v6：卡通重绘与挖宝竞争

先使用内置 Image 生成美术概念稿、搬运工四帧透明图集与挖宝人四帧透明图集，然后接入实际游戏。素材及生成提示词记录在 `sand-marbles/assets/README.md`；资源随 GitHub Pages 静态部署。

## 最终行为

- 搬罐的四个移动段由1.4～1.5秒缩短为0.65～0.7秒，约两倍移动速度，保留发力、换脚、负重起伏、扬尘、喘气和分段返程。罐身、标签、已收集珠子及真实接珠判定继续一起移动。
- 沙土、地底、石块、彩色珠子、厚玻璃罐、按钮、选关和结算改为暖色卡通风格。手机有紧凑触屏布局，桌面侧栏展示生成的探险插画。
- 挖宝人从第2关出现，首次挖沙后开始行动，背着藏宝袋沿真实路径追逐尚未入罐的珠子。会实际挖掉沙子、绕开石块、利用已挖通道更快前进。接近时挥铲和警示加强；音效可关闭。
- 任意一颗珠子进入挖宝人的铲子可触及范围且无岩石阻挡，就失败且无星。没有按时长自动判负的逻辑，也没有数字倒计时。
- 已装罐的珠子安全。挖宝人挖的沙不计玩家用量；15关继续按玩家挖沙量评分。未开始、说明/选关弹窗、后台及结算状态都不推进竞争。
- 角色素材没加载完成时不能启动回合；资源加载失败显示重试入口。无新增存储、后端或外部生成调用，无默认解法或提示按钮。

## 验证边界

- Node 35项：15关各4组随机搬罐种子，真实物理与对手启用时均有三星解法；另外验证挖沙、计分、移动罐口、快速返程、真实抢夺、石块阻挡、边缘珠追踪、已装罐保护、冻结与重置。
- 桌面真实鼠标：第3关11/11三星，快速搬罐与挖宝人同时启用。
- 手机390×844真实CDP触屏：第2关11/11三星、无横向溢出。
- 浏览器等候挖宝人实际开挖并抢到珠子，确认stolen失败、无星、失误回看冻结、重来清空；说明暂停、音效开关、静音、刷新回第一关与零持久存储均验证。
- 浏览器主动阻断角色图片，确认回合不推进，解除阻断后点击重试能恢复。
- 独立代码审查发现边缘珠可能使追踪失效，已修复可达点选择、铲子范围与岩石射线、末端移动精度，并通过新增回归。复查无明确发布阻断。
