# 沙里有珠 · 三方试玩整改记录

目标：三位独立玩家视角评审分别从画面、可玩性、当前竞品比较给出超过 90/100 的评分。评分来自实际浏览器试玩及明确的评分细则，不等同于真人市场调研；不能以自动通关或放宽评分标准代替。

基线版本：`b6c6cac`（线上 v3）。保留 15 关、按挖沙量评星、仅蚯蚓与搬罐机制、无路线提示、默认静音、刷新重置、静态 GitHub Pages。

## 固定评分细则

每项 20 分，满分 100；初评与复测使用相同细则。

- 画面：视觉风格与完成度；字体、对比与信息层级；桌面与手机构图；动态演出与反馈；关卡视觉变化与辨识。
- 可玩性：上手与规则可理解性；挖沙操作与反馈；策略与关卡变化；公平性与物理可预测性；重玩动力。
- 竞品：核心手感；关卡策略；特色；呈现完成度；轻量体验。

### 初评来源与操作摘要

- 画面：独立鼠标通过第1/3/15关，桌面1440×900和手机390×844，三关均三星。
- 可玩性：自行规划通过第1/3/6/9/15关，含第9关失败重试、第6关卡珠修坡后二星、音效开关和三档铲子。
- 竞品：自行规划第1/7/15关均三星，故意错色测试；官方资料对照 [Sand Balls](https://play.google.com/store/apps/details?hl=en-US&id=com.water.balls) 和 [Dig This!](https://play.google.com/store/apps/details?id=se.raketspel.digaround)，未亲玩竞品。该评审曾参与之前代码审查，并非完全盲测。

这三份是AI子Agent通过真实浏览器操作的玩家视角评审，不是招募真人实验。自动化解法回归单独列证，不能替代这些独立试玩。

- 三位评审各自实际试玩并给出评分和建议。

- 物理/评分回归、桌面和触屏交互、无提示、音效与刷新重置验证通过。
- GitHub Pages 发布完成，线上版本与最终受评版本一致。
