# 国王消消乐 — 实现与验证记录

2026-09-17。游戏实现与方案审批分离，制作人独立试玩记录见 `king-match-playtest.md`，设计首轮退回及复审批准见 `king-match-design-review.md`。

## 测试依据

- 制作人按4张参考图和两个视频提出固定砖墙排料机制；主实现也独立抽取两视频时序验证。
- 先写核心规则测试并观察缺失实现失败，再实现纯引擎；两关推荐输入实际驱动物理，不修改计数或状态置胜。
- 第一版制作人静置体验发现12秒保护后耐久耗尽过快。先增加观察宽容测试并看到两关失败，再降低真实接触耗损系数；修复后静置失败分别为36.250秒、29.783秒。
- 同步了并行任务已合入main的“沙里有珠”v4更新，保留其26个测试和原入口版本。完整 `node --test sand-marbles/tests/*.test.cjs king-match/tests/engine.test.cjs`：39通过、0失败。

## 物理边界

1/120秒固定步长，圆形散料、摩擦、低反弹、静态斜坡及砖墙碰撞，依据真实安全出口越线计数。护盾为固定碰撞体，接触密度驱动卡通耐久；人物不是动态刚体，矿石也不是工程级多边形颗粒。素材由image生成，原始PNG保留透明度，原参考不发布。无存储、无遥测、无付费资源。
