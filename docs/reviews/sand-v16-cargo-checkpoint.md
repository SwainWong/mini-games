# v16 矿车装载与随机轮控阶段记录

## 已实现

- 车斗保存实际珠子对象（颜色、材质、价值、收集时间和车内偏移），逐颗显示；计分身份不复制，已得分不因后续落石丢失。
- 容量为本关该色珠子数加2。落石不毁车，按旋转投影面积占槽；满车接触使珠子向外弹起，仍为活动珠子，不在车口直接吞掉。
- 连续椭圆首接触决定承载。多车共担石头形成传递承载组、等位移；碰撞覆盖车体、货石、自由石和墙；普通炸药仍可伤车。
- 占槽按接触时刻进入统一事件队列，同刻先接珠再落石；若最后一珠更早结算，未发生的落车恢复为截止时刻的空中状态。
- 四车全部可以轮控，洗牌无放回，每轮覆盖所有存活车，轮次之间不连选同一车。3.5–5.5秒接管，保留平滑刹车；预排随机周期时检查最坏刹车时间和25秒上界，必要时缩短本轮停留至3.5秒。
- 所有新行为是本地 v16 代码，尚未合并或部署；线上仍为 v15。
