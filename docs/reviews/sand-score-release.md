## 审核发现并关闭

1. 新石头成为轨道障碍时，旧clamp可能将矿车400→431瞬移：改为单步有限阻挡/退让，独立回归和正式回归通过。
2. 爆炸使用扁石头外接圆会命中可见范围之外：改为到真实椭圆的最近距离，矿车使用车体矩形；独立/正式回归通过。
3. 首版车队可长距离漂离起点使初关过度依赖随机：按36/50/65递进限制车程，并保持随机步长/停顿。
4. 部分压力盘太靠近默认收集路线：调整第8/11/15关支路坐标，补不点火与点火双路线验证。
