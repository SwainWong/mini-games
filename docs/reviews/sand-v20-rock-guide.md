# v20：移动岩石脱困与图片指南

## 岩石边缘卡住

复现：盗宝人初始坐标(205,320)，岩石(280,300)、半径(60,40)。岩石向左缓慢移动10像素后，人物仍在可见石头外，但进入了寻路预留的13像素边界。旧版20秒后仍停在原处，换目标和重算路径均无法取得合法起点。眩晕期间岩石继续移动也可复现。

修复在每次AI更新之前执行局部碰撞分离，包括眩晕、休息和拾取状态。先尝试旋转椭圆的最近边界，受其他岩石或地图边缘限制时搜索同一邻域的合法出口；不跨过其他岩石。脱离后清空旧路线并重算。正在握持的原珠子会被释放并短暂无偷取保护，不复制、不直接入袋。正常处于合法位置的行为不变。

四项新增回归覆盖慢移动挤压后继续取珠、眩晕期间持续挤压、24个旋转/方向组合的局部分离，以及拾取中断的珠子身份守恒。修复前两个复现用例均失败，修复后通过。既有静态岩石绕行测试继续通过。

## 图片指南

新增四色珠子→同色矿车2×2图片，使用现有矿车作为 Image 生成参考；箭头和车沿/车牌颜色一一对应。中文标题、四色名称、普通珠同色+10、错色+0且不扣已有分数使用HTML可访问文字显示。首次开局置顶呈现，同一页面会话不重复强制出现，可从“图文指南”随时查看。

390px手机和1200px桌面检查图片、准确规则文字及开始按钮；确认手动打开指南暂停时间，第二关不重复显示首次匹配介绍，但手动指南依然可见。刷新仍重置会话，无持久存储。

图片和生成提示位于 `sand-marbles/assets/color-match-guide-v20.png` 和 `color-guide-v20-prompt.md`。缓存版本24，发布入口 `sand-marbles/?v=20`，物理快照协议沿用18。

## 最终验证

255项自动测试全部通过。真实浏览器手机触控挖开第8关岩石下方，岩石实际下落；随后持续采样中盗宝人移动约309像素并继续追珠，无脚本错误。这是移动岩石的实际输入回归，不将其等同于用户截图的逐帧重现；截图未包含关卡编号，卡边界根因使用上面的确定性用例验证。图片指南的首次/手动/跨关卡行为及手机、桌面布局全部通过浏览器验证。
