# 沙里有珠 v7：2.5D 角色与真实干扰

## 成品行为

先由内置 Image 生成统一暖光、陶瓷与黏土材质的 2.5D 贴图，再改 Canvas。四份最终素材均纳入 `sand-marbles/assets/`，提示词和实际尺寸记录在该目录 README。

搬运工与罐子采用完整六帧素材，手掌握外侧把手。每帧实测开口坐标后映射至物理罐口；罐子、色标和收集计数始终跟随同一目标。走路换脚、负重停顿、擦汗、摸下巴思考、抬罐有不同动作。随机步长、停顿和折返距离，回到原位后休息；罐口在 x=104..456 范围内，给完整人物留出空间。第十关慢落珠较多，搬运最大位移65，其余关90；相邻罐口距离至少96。

盗宝人从第二关出现。移除角色旁全部文字标签；挖沙基础速度由10/11/12提高到22/25/28，空路乘1.85，每0.35秒重算追踪。0.8秒起步动作之后真实追珠；只在实际碰到珠子时失败，无隐藏时间判负。首个竞争关开挖后不采取行动，实测15.3秒抢到珠子，旧版相同浏览器测试33.7秒。

蚯蚓从第五关起每关2—4条，速度41—57，挖掘半径17。活动区横向半宽48—60，各自爬行，在真实沙路上开岔道，撞石转向。修复斜向接触岩石时停住的边界问题。初始位置和活动范围避免不可挽回地直接掏空高处珠子的承托层，仍需玩家观察/处理被挖宽的路径。

评分、无默认解法提示、音效选择、刷新清空保持原规则；无持久化、后端和分析请求。
