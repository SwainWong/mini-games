# v15 操作员动作残影修复

## 原因与处理

v14 用中立与转向两张人物图做互补透明度混合。即使透明度总和为1，两幅轮廓仍会同时出现，尤其是手臂、肩膀和靴子。

v15 先生成9帧连续转向图、左右各4帧指车图，再按实际车速/动作时间选取一张完整不透明人物。指车过程为抬手0.14秒、伸手0.14秒、保持0.24秒、收手0.18秒；转向按实际 steering 对应左4帧、中立、右4帧。人物保持右下角背面视角。

原始生成图的行列分布不是精确等分，使用实测边界和脚底锚点裁片，防止上一排靴底进入下一帧。不修改矿车运动、碰撞、灯色或得分规则。素材与完整提示词见 sand-marbles/assets/README.md。

## 验证方法

- `browser-v15-operator.js` 观察真实 Canvas drawImage 调用，检查每个已绘制人物帧只有一张且 alpha=1；覆盖9张转向图、4个指车阶段，保存手机/桌面截图。
- `node --test sand-marbles/tests/*.test.cjs`：119项回归通过。
- `browser-cart-edge.js`：实际鼠标/触屏沿车口接珠、外侧漏接、结算冻结、重来和刷新通过。
- 发布后在 GitHub Pages 再运行人物绘制回归，核对新素材与脚本实际返回内容。
