# v14 方向盘控制台与连续车速

## 目标与实现

操作员背对玩家、面向矿区，方向盘控制台整体移至右下角。先通过内置 Image 生成六个背面操作姿势（中立、左转、右转、指左、指右、惊吓），再生成无人方向盘台、四灯矿井信号柱及四种发光灯片。逃岗延用相同角色已有跑步图集。

原算法每移动约 0.65—1.45 秒就休息 0.55—1.65 秒，起步直接赋予 34 像素/秒，造成走停和速度跳变。本版改为固定步长的连续速度控制：保留轨道碰撞与推车链，每次一个目标矿车获得驱动力；匀速巡航前渐加速，到行程端点提前减速再折返。切换控制前先制动旧车，之后点亮新车颜色的灯，避免多个驱动目标和指示含义不一致。碰撞仍可以推动相邻未驱动车。

早期仅一辆车可被驱动；后期沿用每关原有可驱动车数量，但由一个人依次切换。控制持续约 4.5—7 秒，切换与折返间隔不使用每秒随机停顿。灯的琥珀、青玉、冰蓝、玫瑰顺序固定，无该色车的灯熄灭。亮灯绑定真实驱动目标；操作员受惊、逃岗、所有车损坏时熄灯。受惊急停仍保留，恢复时平滑起步。

指车动作发生在切换目标后的短时间，手臂指向该车实际所在方向；另一只手握方向盘。方向盘左转/右转姿势取决于真实车速方向，不使用独立随机动画。车斗标签补充小亮标辅助对应，手机上也可辨认。

## 验收

覆盖速度连续性、无反复停顿、端点减速、单驱动与灯色一致、切换无串色、推车链、104 像素互斥、损坏车与落石障碍、受惊停机。重放十五关四种子与炸药路线；如轨迹时机改变，更新真实输入的等待时间，不降低过关分数或停用机关。浏览器验证右下角布局、背面朝向、指向/转向/灯色、实际触屏、暂停、重来和刷新。
