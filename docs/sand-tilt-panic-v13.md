# 沙里有珠 v13：失衡落石与爆炸反应

## 实施方案

- 岩石共用旋转椭圆几何：画面、沙格遮罩、珠子/盗宝人/虫子碰撞、炸药附着点均跟随角度。底部按宽度采样支撑，重心不在支撑区间时绕接触面倾斜；不足 22% 的碎土承载会碎裂。保留约半秒松动过程，不显示落点阴影、投影柱或虚线落点。
- 每关最多四辆矿车。原来的多辆车运动命令仍可并行，但全部来自底部唯一一名摇杆操作员。碰撞、缓冲器、轨道顺序、车斗判定维持一致。
- 每次有效爆炸都让操作员惊吓 0.9 秒并刹停矿车；35% 概率逃岗，退出后整局停机，矿车仍可接珠。留岗者恢复控制。逃跑动画不带控制台一起走。
- 盗宝人受惊半径 190 像素（爆炸破坏半径仍为 78）。范围外无反应；范围内先惊吓 0.55 秒，再以 50% 概率弃袋、50% 概率带袋逃离。近距离爆炸先踉跄 0.35 秒，再进入惊吓与逃跑（落石眩晕仍为 4 秒）。落石眩晕会中断逃跑但不会取消逃离意图。
- 逃跑沿避开完整岩石的路径到左右边界，挖沙速度提高；到边界才退出，不瞬移。袋子负重、破漏规则继续有效。离场后不会偷取，也不能再次受惊。
- 弃袋有实际位置和打开动作，原有珠子逐个掉出，可重新接取；不凭空加分。待打开袋子、手中珠子、可炸回/漏回的袋中珠子计入剩余得分机会；真正带出屏幕后才失去这部分机会。
- Image 生成统一风格的摇杆操作/惊吓/逃跑素材，以及盗宝人惊吓/弃袋/逃跑和闪光→火球→烟尘→余烟四阶段爆炸。特效以同一爆点为中心，逻辑破坏范围不随贴图大小改变。

## 验证

新增测试覆盖薄土柱、偏侧支撑、旋转碰撞与炸药附着、惊吓范围/概率两分支、弃袋珠子身份/分数、离场后停止偷盗、操作员逃岗后车辆静止。保留全部关卡解法、边缘接珠、车辆互斥和计时结算回归；浏览器检查桌面与移动端实际输入、重来、刷新和图鉴。发布前独立 Agent 审核。
