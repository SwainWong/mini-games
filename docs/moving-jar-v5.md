# v5：罐子是实际移动目标

用户指出 v4 的固定接珠盘使搬罐失去意义。本版删除固定盘、暂存队列和回家转运；此前 v4 评分不证明新规则正确。

罐身、罐口、颜色标签和已装入珠子一起移动。每个物理步检查珠子穿越实时罐口的位置（含提起高度）；旧位置不再接珠。错过或落入错色罐失败。罐口绘制和物理共享几何。罐子始终在屏幕内，搬运工走停交替，回家休息4.5秒。

罐子整体提高至沙土出口下方，避免移除接珠盘后凭空增加很长的自由落体。保持十五张地图、四种珠子、蚯蚓、按挖沙量评分，无默认解法或提示按钮，无持久存储。
