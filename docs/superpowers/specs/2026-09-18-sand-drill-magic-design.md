# 沙里有珠 v16：钻机盗宝人、矿车装载与魔法袋

状态：第二版已通过专业设计Agent复审；等待用户美术选择后实施。审核记录见 ../../reviews/sand-v16-design-review.md。此文档不表示已实施或已通过玩家评分。基线 sand-marbles 为 dea3d67；分支继承最新主线 c089396，其他游戏不改。

## 1. 目标、边界和门禁

完整覆盖本轮盗宝人4项、矿车4项、魔法袋2项、铲子和提示气泡要求。保留15关、手机触屏、桌面鼠标、同色得分/错色0分、达标后继续冲分、时间/机会耗尽结算、挖沙量评星、仅本页状态、可关闭音效。

顺序：生成多版效果图 → 游戏专业设计 Agent 审核本方案 → 用户确认钻机/捡珠美术组合 → 完整实施及自动化回归 → 3名独立小游戏玩家 Agent 实际控制浏览器 → 修复/复测 → 发布并验证线上。设计通过不等于试玩通过；不预设或要求审核者给高分。

## 2. 美术备选与资产契约

三张方案板均展示钻土、捡珠四阶段、坐下休息：
- A：手持双把螺旋钻机 + 双手捧珠（推荐）。手机尺寸最容易读懂，工具、双手、宝袋不会相互混淆。
- B：背负动力钻机 + 机械夹爪。机械接触清楚，但动力背包和藏宝袋需要严格分开，视觉更复杂。
- C：小轮重型钻机 + 托盘收珠。重量感强，但占地较大，窄坑转向和物件遮挡成本较高。
可交叉选，例如A钻机+B拾取。方案板仅用于确认方向，不能直接切下当成最终动画帧。

选定后生成统一比例的独立透明素材：钻机待机/钻进6帧、持机走路6帧；拾取8帧（探手2、触珠2、抬起2、入袋2）；满载慢走4帧、坐下/坐姿/擦汗/起身至少6帧、受惊/弃袋/逃跑6帧。角色不烘焙宝袋、珠子或紫色补画手臂；每帧记录手掌、袋口、脚底、钻头接触点，左右翻转同时翻转锚点。主体与手部遮挡层保持一个身体，禁止交叉淡化。紫色仅用于真实帽子/背心。

方向盘另拆：固定木底座/立柱、绕固定轮心旋转的圆盘、背面人物及双手动作；底座和轮心坐标全程不变。人物双脚固定，指车时单手离盘。需补开袋、炸弹闪光/爆炸/烟尘、废珠裂纹、沙流回填、车内宝珠和岩石装载素材。

## 3. 盗宝人状态与寻路

### 3.1 钻土

移除高频挥铲。状态为观察→持钻接近→钻头接触土壁→连续钻进→停钻拾取。只有钻头接触有效沙土才挖沙、扬屑、耗钻进体力；身体仅轻微震动，钻头旋转解释连续挖掘。钻头世界位置同时用于图像、扬屑、地形挖除。空洞中走路，不空转扬土；岩石仍不可钻穿。音效开启时，钻头实际接触沙土才播放低音量机械声，停止或静音立即终止。

### 3.2 拾取可中断、不会吸取

接近至手长内→下蹲伸手0.24秒→接触并抓住0.16秒→抬起0.30秒→放进袋口0.30秒。接触之前珠子仍自由运动；接触后绑定真实手掌锚点；到袋口后才计入被偷并消失。中途岩石阻挡、珠子滚远或受到惊吓时，立即取消并释放原珠子，不复制、不丢失。工具停在身侧，另一只手扶袋口；不绘制紫色线段代替手臂。当前game.js的rivalDraw在拾取时用#844cbd、宽6的直线连接贴图手掌和目标珠子，这就是参考图中突兀紫色物体的直接来源；新方案删除该补画，改为完整动作和受手长约束的接触点。

### 3.3 负重、休息

用同等体力下的实测速度比较，而非仅看贴图大小。负重倍率拟为 max(0.38,1/(1+0.10*n))，0/3/6/10颗分别约100%/77%/63%/50%。体力倍率平滑限制在0.8–1.1；负重消耗倍率1+0.06*n，按实际位移和成功钻土计算，碰撞停住不空耗体力。空载基础速度按关卡30/34/38像素每秒，空道1.65倍，听声短冲刺保留。

体力≤20触发收钻→卸袋→坐下→擦汗/喝水→起身，静止恢复到80且至少2秒再走。爆炸惊吓的坐下休息至少1.5秒，不拾取、不挖土；不因听声强制取消休息。大袋随真实数量缩放、身体前倾、脚步放慢；保留>6颗每移动1秒5%破袋，以及漏珠可追回规则。

### 3.4 已复现的卡死与修正验收

岩石中心(280,300)，半径(60,40)，盗宝人(279,247)，珠子(400,300)：A*首路点(296,248)穿入膨胀岩石；15秒零位移，仍反复跑步/休息。

路径起点使用角色实际坐标，连接多个视线可达网格节点；终点为可拾取接近位置，不要求站在珠心。每段都通过相同岩石碰撞判断。目标移动、落石移动、回填时使路线失效。非休息/拾取状态0.75秒无有效位移则更换接近点，1.5秒仍失败则给该目标2秒冷却并改追其他珠子；仅剩一颗不可达时回到巡查，之后重试，不原地抖动。

测试含左右石沿、转角、窄缝、边界、移动珠子、接触前滚走、抬珠撞石、落石/回填之后、只剩一珠、两珠来回切换；可达应在路径长度/有效速度+明确动作等待上界内拿到，不可达应转入巡查且有后续重试。测试不直接改状态来宣称通关。

## 4. 矿车装载、岩石与控制

车内珠子来自实际收到的珠子数组，保留颜色/材质/价值和稳定槽位。珠子落入后短暂下沉与弹跳，随后留在车斗；底部为车内层、上面为珠子、最上面为前车沿，不在车体外浮动。数量少也必须看得见，满载呈堆叠。既有得分不因后续事件倒扣。

新增每车 capacity、cargo、rockLoad。容量初始为该色关卡珠子数+2，正常接珠不会凭空装满。岩石占用按其投影体积折算槽位，同时使用真实几何阻挡落珠；被石头占满则珠子在石面弹开/滑出，不瞬间消失，也不得分。留有空位的部分可继续接。已收珠子保留在车内并占槽位；不静默丢掉已收集物。

落石碰车不再调用损坏矿车逻辑。能落入车斗的石头绑定车位、随车移动，从自由落石/轨道障碍列表剔除但保留对珠子的碰撞；过宽岩石架在车沿并封堵受覆盖的开口，按原尺寸显示，作为随主承载车移动的货物，其外形会限制相邻车的位移，不能与邻车穿模。砸中虫子/盗宝人规则保留。一般引线炸药仍可炸碎石头；矿车是否受炸药损坏沿用现有规则（魔法袋小爆炸不损坏车体）。

剩余可得分按颜色、实际珠值、车容量及可移除岩石机会求安全上界：有可触发炸药能清走货石时必须保留这部分机会，不因当前堵塞提前判死。不可恢复的满车不能无限计分潜力；HUD和真实接珠必须一致。

四车控制采用有种子的无放回随机轮控：一轮中每辆可用车恰好被选一次，每轮重新洗牌，跨轮避免连续选中同一车。每次3.5–5.5秒，先减速停稳、切灯、指车、再平滑起步，四车最大等待不超过25秒。单轨不能交换顺序、碰撞推移保留。因堵塞连续0.8秒无法动则提前切换，不把控制耗在一辆死车上。

### 4.1 落石首接触与承载组

落石与车沿使用连续碰撞求首接触时刻，岩石停在接触平面，不改变水平位置、尺寸或朝向。该时刻投影覆盖车口的车均进入承载集合（按车ID稳定排序，最先接触者为主车，同刻取最左）。只覆盖一车则单车承载；覆盖多车则组成临时承载组，保存每车与石头的相对偏移。组内车同速同位移，空间由整组左右边界和外部车约束求交；没有移动空间时整组停住，控制员可切换其他车。不能通过吸附、缩小石头或把邻车挤出屏幕解决冲突。

岩石负载按横向分配：对每辆受影响车，f=岩石横向投影与该车口重叠宽度/(2*岩石横向半径)，占用槽位=ceil(π*rx*ry*f/(π*8²))，裁到[0,capacity]；同车多石累计后裁到capacity。现有已收珠子保留，freeSlots=max(0,capacity-cargoCount-rockLoad)，过载不删除已计分珠子；碰撞形状仍用实际旋转岩石，槽位不替代几何。石头只擦到车侧未达到车口承载条件时，落到地面形成轨道障碍。爆破移除货石和相应占位/承载约束，剩余石头重新建承载组。存活岩石不因本轮回填重复计算为自由落石。

补测四车贴近、双车同刻接触、超宽石覆盖多口、墙边无空间、组推外车、两石同车、已满车落石、爆破解除组，均禁止车序交换/物体瞬移。

## 5. 随机魔法袋

魔法袋外观与固定+30宝箱明显区分，首次图鉴说明风险。不再显示必得+20。初版分布：50%+20、20%+40、15%小炸弹、15%全沙回填；每袋在开局按独立种子预定结果，本关重来保持结果，刷新重置。UI未揭晓时最高可得按+40安全上界，触发后按实际结果重算。宝箱仍固定+30。

小炸弹：碰袋→弹出炸弹→0.9秒闪烁/引线警告→半径72爆炸→0.5秒烟尘。范围内盗宝人必受惊：50%坐下休息/恢复，25%弃袋跑掉，25%背袋跑掉；不在范围内不触发。范围内尚未结算的珠子降为价值3的灰色裂纹废珠，保留原色小印记；同色车+3，错色0，重复爆炸不继续降值。袋内尚可追回的珠子若在爆炸范围也降值，已得分不改变。驾驶者按既有爆炸惊吓/逃岗机制处理。

全沙回填：0.35秒袋口沙旋警告→1.2秒自上而下沙流覆盖与坑壁逐渐合拢→0.25秒尘雾散去。重建全部沙坑，包括初始空道；仅现存珠子、角色与岩石真实占据体积留最小安全口袋，避免物体被刷入实体。过渡期间暂停物理、计时与玩家输入，结束后同时恢复，不把动画等待偷偷算作惩罚。计分、剩余时间、已收珠、已开袋、机关存活/离场状态不重置；重建岩石遮罩与AI路线。重挖同一格不重复计玩家沙量（保留本局曾挖格掩码），三星预算需按固定铲重新校准。

关卡可解性：15关基础路线均不得依赖随机袋奖励。魔法袋必须可绕行；含魔法袋的关卡额外验证炸弹/回填分支存在可操作解法，包含连开多个坏结果。合理操作仍可能因误挖/时间消耗失败，不承诺任意错误操作都可挽救。必要时调整门槛或袋位置，先记录最终15关目标、时间、容量、预算，再通过真实物理路线回放证明，不能只降低测试断言。

### 5.1 魔法事件与回合结束顺序

每袋最多生成一个事件，生命周期 pending→warning→resolving→done。同一物理步按实际接触时间排序，完全同时按触袋→有效接珠→魔法/伤害→偷取处理。即时奖励在触袋时记分；炸弹与回填进入队列。所有尚未处理的奖励/魔法事件都会阻止“珠子耗尽/机会不足”的提前结算；HUD将“效果处理中”作为短暂状态，不显示已通关又撤销。

魔法事件按触发时间FIFO执行，单次过程不生成新随机袋；魔法袋炸弹和回填不会彼此在过渡中重入。回填期间暂停世界物理/时间以及其他炸药引线和AI状态计时，当前回填动画用独立表现时钟推进，结束后统一恢复。队列中的事件不能无限等待，炸弹最多1.4秒、回填最多1.8秒，不允许再次开同一袋。

关卡时间到0时立刻锁定玩家输入，不再接收新触发和新得分接触；处理截止物理步内已经排定的接触，然后按FIFO完成已触发魔法事件的效果与演出（珠子/车/AI位移冻结，受影响珠值和恐惧状态仍更新）。不因演出额外给玩家得分时间；既有得分不倒扣。队列清空后显示最终结算。非超时情况下最后一珠触袋并入车，也要等待已触发效果处理完毕再结算，不吞掉动画；之后使用真实得分/珠值/机会判断。

补测最后一珠触袋并接取、最后一珠触袋后被偷、倒计时末帧触袋、两个魔法袋同帧、回填期间引线将爆、降值后最低分不足、结算后不能重复事件。

### 5.2 可复现试玩入口

正常初始化支持可分享的 `?level=8&seed=12345`，合法范围level=1..15、seed为32位非负整数，无效输入回退默认。固定种子只确定关卡随机序列，不跳过图鉴、不改分数、不关闭对手；snapshot记录版本/关卡/种子，试玩用正常UI和鼠标/触屏。每次关卡重来沿用本局种子。普通无seed网址刷新清空进度并创建新种子；显式seed链接刷新也清空进度，但保持链接指定随机种子，方便复现。AI、车控、袋子分开随机流，渲染粒子不消耗游戏随机数。对应结果种子由正常初始化测试枚举获得，不能修改world伪造事件。

## 6. 铲子与驾驶者气泡

移除“精细/常规/宽铲”三个选项，统一半径20的铲子；触屏和鼠标按相同世界坐标换算。划动速度不暗改宽度，挖沙质感与评星保留。省下的HUD空间用于紧凑关卡机制信息，不再增加复杂工具。

左下提示移到右下驾驶者头顶、尾巴指向驾驶者。文字自动换行，最大宽度150世界像素，避开车口、灯柱、分数和手指挖掘区；使用事件优先级和冷却，不每帧闪换。驾驶者逃岗后改为控制台上的无线电提示，并移除人物气泡尾巴；没有驾驶者的1–2关用同位置无线电提示，不凭空增加驾驶角色。辅助DOM aria-live同步文字。

## 7. 实施模块和验收

新增独立动作帧/锚点表、拾取状态机、装载容量和魔法事件模块，复用现有core/rival/hazards/cart-crew接口，避免把全部行为塞入game.js。snapshot仅暴露调试观察数据，不加通关按钮或写世界API。新素材使用相对路径，保留生成提示词和裁片说明。

自动验证：
1. 上述追珠卡死最小案例、至少40组地图/种子及移动珠子长跑，无永久无进展或重复拾取；手掌/珠/袋口接触守恒。
2. 同体力下0/3/6/10/20颗负重速度单调递减；坐下不移动/不偷；0位移不空耗。
3. 矿车真实接珠与渲染数量/颜色一致；石头占槽、随车、弹珠、爆破清槽，计分机会不提前归零；车沿旧480组合回归。
4. 随机轮控100种子，四车每轮全覆盖、不同轮顺序变化、25秒内无饥饿；车不重叠，底座/轮心像素位置固定。
5. 袋所有结果、边界距离、废珠价值、回填暂停/恢复、不可重复开袋、未知上界、结束条件；15关及各坏分支真实路线回放。
6. 手机/桌面真实鼠标/触屏，音效、图鉴、暂停、重来、刷新和Pages相对链接。

玩家验收：3名独立小游戏专业玩家 Agent，各使用独立浏览器会话和同一待发布构建；至少各实际游玩6局，覆盖1/3/8/12/15及一关自选。不得仅看截图或读取测试结果给分。实际尝试抢珠、绕石、接珠、观察满载/轮控、引爆或回填；自然局未遇到某个结果须继续玩对应种子，不可声称覆盖。每名记录URL、构建、操作步骤、截图、结果及美术/可玩性/合理性各0–100分，综合均分。每一维和每人的综合分都>90，三人均分也>90，且无严重卡死/穿模/无解，才算通过。分数不得预填；不通过记录问题→主Agent修正→三人复测受影响内容和一次综合游玩，保留历轮真实评分。

当前证据仅支持：存在可复现的寻路首段阻塞；当前已实现但反馈不足的负重；固定循环轮控；缺失装载展示/容量；随机袋尚未实现。没有试玩评分或完成声明。
