# 沙里有珠 · 积分矿场设计 v1

状态：高级游戏设计与高级游戏体验Agent均已定向复核 APPROVE，允许主Agent实施；实际试玩验收尚未开始。用户已指定“方案审核通过后由主 Agent 执行”；本文件与对应实施计划是本轮执行边界。已有矿车边缘修复一并保留。持续演进以本文数值、关卡表与验证记录为起点。

## 1. 目标和方案选择

从“全部珠子归位、一次错误即失败”转为“规划沙路，争取足够积分，利用环境与对手争夺”。保留十五关、触屏/鼠标、挖得少获高星、可关闭音效、页面刷新从头开始。

考虑三种方案：A 仅放宽漏接次数，改动小但难容纳宝袋；B 目标积分 + 剩余分值判负，能容纳环境互动且容易看懂；C 加倒计时/商店/永久升级，会偏离当前轻量试玩目标。本轮选择 B，不加数字倒计时、商城、账户、存档或网络数据请求。

美术参考用户给出的经典挖矿游戏：暖棕横向土层、粗线条金属/木矿场边框、清楚的地下剖面与顶部 TARGET / SCORE 信息层次。使用原创图形和已有/新生成卡通素材，不复制参考里的国王、骷髅、商标或原始贴图。角色保留体积光影，整体颜色降低亮黄面积，加强土层与隧道的深浅区别。

## 2. 积分、结算和星级的唯一规则

- 所有颜色、材质珠子均值 **10 分**。同色且完好的矿车接住：+10；错色、车已损坏、漏接或被盗宝人拿走：该珠子退场，+0。已获得的分数不会被扣掉。
- 问号袋被任意一颗珠子实际碰到时打开：+20；后段宝箱：+30。一次性，珠子继续运动，同一帧多珠碰撞也只计一次。奖励固定在关卡配置中，不靠随机奖励决定能否过关。未打开宝物显示“？”及物件形状，打开后明确飘字。
- `score >= targetScore` 立刻通关并冻结场景；不要求剩余珠子也入车。
- `remainingPotential = 可进入完好同色车的活动珠子数 × 10 + 未开启宝物分值`；若活动珠子数为0，未开启宝物也不再可得。此值是几何可达性之外的保守上限，不把沙中暂时静止判成损失。
- 若 `score + remainingPotential < targetScore`，判“积分已不足以达标”。若仍有理论机会，允许继续挖沙和使用机关；珠子停住时提供“可继续挖 / 重来”的状态反馈，不自动超时判负。任何时候可重来。
- 破车不直接判负：其颜色珠子的入车分值不可再得，但仍可撞宝袋；其他车和宝袋可能帮助达标。展示 +0 与破车状态，绝不仍计为接住。
- 同一物理步中的交互统一进入事件队列，每项含0–1的接触时间u。先按u排序；同时间按“宝物 → 当时有效的入车 → 伤害/眩晕 → 偷取/其他损失”排序，处理完这一时间组再统一判断。**已达目标优先通关**，终局后停止后续组；已眩晕的盗宝人不能在该时刻偷珠。岩石早于入车砸坏车则该球+0，入车早于砸车则先保留+10。独立模块不调用结算。
- 通关后继续按挖掉的新增沙面积评 1–3 星，沿用逐关显示的 three/two 额度。未达标/失败无星。关卡目标降低后先保留现有额度，避免与新增机关同时改变两个评分难度轴；后续可根据试玩统计调紧。
- HUD写“当前分 / 目标分”和“剩余最高可得”，后者是理论上限。举例：第1关从0/40开始；错色显示“错色 +0 · 已得分不扣”，偷珠显示“被偷 +0”；积分不足时给出“当前20 + 剩余最高10 < 目标40”的具体原因，不使用会被理解成扣除已得分的负分飘字。
- 本次打开期间记住最高星级和最少通关沙量。刷新重置进度、首次提示记录和音效状态。不读写 localStorage/sessionStorage，不添加后端、分析或遥测。

## 3. 珠子与矿车的接触契约

共同几何：开口中心 y=590，内半宽46，画面、碰撞与失误标示读取同一份定义。珠心向下穿过可见开口且在 ±46 内，即由车沿滑入；不额外减去珠子半径。用珠子与矿车的相对运动插值求穿越瞬间，不使用原车位或帧末车位代替。

错色/漏接改为该珠子 +0、轻微提示、继续游戏。若这次损失导致积分不足，冻结在本次接触时刻：珠子与矿车同时停在该时刻，失误圈保留实际珠径。不在入车后“回收”早已落到车斗下面的珠子。

## 4. 盗宝人：体力、听觉、休息和抢珠

从第2关出现。基础速度按难度30 / 34 / 38逻辑像素每秒，空通道倍率1.65，挥铲节奏有明显快慢变化。状态定义：

| 状态 | 条件与时长 | 行为 |
|---|---|---|
| 精力充沛 | 体力70–100 | 挖掘速度×1.25，明显用力挥铲 |
| 正常 | 体力35–70 | ×1.0 |
| 疲劳 | 体力20–35 | ×0.65，动作幅度减小 |
| 擦汗/喝水/休息 | 体力≤20；至少2秒，恢复至85 | 不走、不挖、不偷；按动作切换，恢复26体力/秒 |
| 听见动静 | 120像素内有速度≥65的活动珠子；冷却6秒 | 0.35秒侧耳，出现声音弧线；低体力仍需完成休息 |
| 追赶 | 听觉后且体力>25；1.3秒 | 速度×1.5，额外消耗体力；期间不重复触发听觉 |
| 装袋 | 真正够到珠子；0.9秒 | 取走一颗后展示装袋动作；冷却内不能连拿整堆 |
| 眩晕 | 落石或爆炸击中；4秒 | 不走、不挖、不偷，头顶转星；恢复后重新寻路 |

工作消耗10体力/秒，追赶额外8/秒，空地跑动消耗6/秒；休息恢复26/秒。体力条是角色头顶短条，配合动作和颜色，不添加“盗宝人盯上了”等常驻文字。听觉来自游戏世界中珠子的运动，与用户是否开启音效无关。重复挖空洞不能无限触发听觉。

每次偷珠仅损失该珠子的10分机会，不直接结束；状态记录盗取数量。仍沿真实路径绕岩石，岩石移动/爆碎后重建寻路障碍；不能穿石偷珠。被落石碰到时移到邻近可站立位置，避免一直被压住而反复延长眩晕。

## 5. 落石：支撑、预警、碰撞

所有石头都属于可落物体，不保留“看起来是石头但悬空不落”的例外。第2关首次介绍；先沿现有地图布置，教学关岩石远离车道中心，正常路线无需触发落石。

- 用岩石下缘7个采样点检测沙/其他岩石支撑。少于2点支撑时立即抖动、掉细砂并显示下方落区；连续预警0.55秒后才开始下落。支撑恢复即取消预警并把计时归零，不能同一帧刚显示预警就掉落。
- 下落有重力，按最多2像素子步处理碰撞，避免穿过薄沙层和角色；重新获得支撑或落到地面后停止。岩石不是自动穿土钻头，不会强行清空完整沙层。
- 动态岩石实体与可挖沙层分开存储：旧岩石占据区域变为空洞；移动后的视觉、珠子碰撞、盗宝人寻路和沙不可挖区域一致。岩石本身被划过不扣沙量。
- 落石碰到矿车：矿车成为不可接珠的残骸；车沿/色牌变暗并裂开，队友退开。残骸留在单轨上，其他车不能穿过。只有足够落速的首次冲击造成砸坏，不能每帧重复事件。
- 砸到盗宝人：眩晕4秒，保留角色存活。砸到蚯蚓：该虫退场，不再挖路，卡通烟团表现，无血腥。
- 珠子是坚硬宝石：与岩石碰撞滚开，不因落石/爆炸直接消失。仍可能随后漏接。岩石落到轨道上形成车的实体障碍。

## 6. 引线炸药

第8关引入，必须由珠子实际接触压力盘启动；不能直接点击引爆。压力盘、引线、炸药包在画面中连续可见。固定3秒引线，沿线移动的火星显示剩余过程；暂停时火星和物理一起停，不显示数字倒计时。

爆炸半径78，启动后用淡色范围环清楚显示危险区。范围内岩石被炸碎，盗宝人眩晕4秒，蚯蚓退场，矿车可被炸坏；宝石获得轻微推力但不扣分、不销毁。只有珠子碰撞打开宝袋，爆炸不额外随机给分。土层在爆炸范围内被挖开，属于机关免费挖沙。不可穿屏影响另一边。

炸药贴在对应岩石上，岩石移动时贴附点一起移动。若对应岩石在点燃前被其他爆炸摧毁，炸药同步失效并熄灭，不留下悬空的危险物。已点燃的炸药被相邻爆炸波及则本次一起引爆；每份炸药最多执行一次。多个炸药独立压力盘，保留清楚的引线连接。

本版每关最多2份炸药；压力盘放在可见的支路上，不放在开局珠群里，避免加载后无操作自动引爆。引爆是一种可选解法，不作为每关达标的唯一途径。

## 7. 多矿车与角色比例

第3关一名队友；第9关开始2名，第12关3名，第14、15关每车一名。每关随机选颜色分配，分配后不瞬移换车。队友约78–82像素高（当前约60），车体约78像素；手掌定位在侧面握点，脚在轨前地面，角色不遮挡车斗。多个队友站在各自车的前左侧，不相向叠在两个车之间。所有角色面向右方，回程采用拉车姿态；手掌世界锚点(x车−24,y654)，足底y706，按实测图集缩放后人物可见横向边界必须在[x车−94,x车−24]内、头顶y≥622。最左车x96时人物左缘≥2；104车距时人物相隔至少34，且人物位于车口/色牌下方。逐帧测试此包围盒，不用理想提示词尺寸代替实测素材。

单轨中每辆车有固定的左右序号。最小中心距104（开口92，留12间隙），车中心范围96–496；所有移动、等待、回程都受邻车与残骸约束。不能换顺序、穿过邻车或回程瞬移；受阻时停下等待，稍后换方向。改变方向前有短暂停步/拉车动作。石头落在轨面时也是障碍，队友不会把车推过石头。

移动用连续目标位置/速度和状态更新，替换“阶段结束把车重设到原位”的做法。推行、拉车、喘气、擦汗、思考、等待、庆祝用图集与姿态配合。不会为了随机性把车搬离屏幕。

## 8. 图鉴与首次出现提示

工具区提供“矿场图鉴”入口，随时查看规则与原创插画。条目包括积分与矿车、盗宝人、推车队友、落石、蚯蚓、四种珠子、宝袋/宝箱、引线炸药、多车单轨。

进入关卡时比较本关元素与本次页面内已见集合。仅有未见元素时显示一张“新发现”对话框，可包含本关多个新条目，每条两句以内（作用+应对）。**弹窗期间一切物理暂停**，点击“知道了，开始开采”才标记已见并开始；没有新元素时自动开始，不等首次挖沙。首次介绍不提供关闭X，Esc和遮罩不关闭；只能通过该明确按钮确认，不会由关闭事件自动标记。任何对话框打开时释放指针捕获、清空活动划线；关闭/确认时重置帧累计时间，必须等待一次新的pointerdown才可挖沙，避免点击穿透、跨弹窗连线或补跑暂停时间。常规图鉴允许关闭X、Esc和遮罩，均遵守此恢复契约。

同一元素以后关卡/重来不再提示。刷新清空记录，与其他进度规则一致。直接选后段关也能看到未见条目，不依赖按顺序通关。

打开常规图鉴不改变已见集合；介绍不是路线提示，不画解法、不提供无限提示按钮。桌面与手机均能在弹窗内部滚动读完，开始按钮固定在弹窗底部且可达，焦点留在对话框中，退出后回到画布工具区。

手机390×844与360×800必须同屏看到当前/目标分、可操作沙层和全部车口。顶部采用紧凑HUD与工具行（页头+工具总高度≤200px），画布保持560:760比例，最大高度为100svh−214px，宽度同时受视口约束；不能让玩家滚屏找车时机关还在推进。图鉴/选关在独立弹窗，不持续挤占棋盘。文字与触控按钮不随Canvas缩成不可读尺寸，最小触控高度36px。

## 10. 实现边界与验证门槛

模块保持静态HTML/Canvas/CommonJS可测形式：`core.js`管评分/珠子与结算，`rival.js`管体力与追逐，新增`hazards.js`管落石/引线/宝物，新增`cart-crew.js`管单轨队友，新增`codex.js`管图鉴内容。`game.js`做输入、HUD与事件表现；地形沙层/石头遮挡分离，物理与绘制读取同一世界对象。

必须验证：

1. 错色、漏接、被偷只损失对应珠子，仍有足够分时继续；达到目标立即过关；数学上不足才失败；宝物只计一次；刷新清空。
2. 四种珠子的左右可见车沿、移动车的插值接触点、错色0分、车毁0分与冻结位置一致；保留v9边缘回归。
3. 盗宝人能经历快挖→疲劳→休息→恢复，听觉受真实珠子驱动且有限冷却，不能连续偷整堆，眩晕时不挖不偷。
4. 落石保留支撑时不落；失去支撑有预警；接触薄沙、车、人、虫有真实结果；没有旧位置隐形岩石、穿石偷珠或重复砸死。
