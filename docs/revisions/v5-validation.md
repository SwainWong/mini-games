# 国王消消乐 v5：斜坡出口

## 原因与修改

旧末端x366到右墙408只有42px，约2.8颗最大直径金子宽。隔离下游承接腔后仍能落料，故不能宣称永久卡死；根因是明显限流/视觉拥堵。斜坡末端向左收18px到x348，净口60px，保留原斜率与16px厚度。共享几何同时派生绘制、粗筛边界、保护腔坡面法线和初始填充，不留下旧隐形末端。不改供料率、金子尺寸、国王受力、HP或两关规则。

曾比较74/82px更大口，但10秒上仓填充降至.567/.302；60px兼顾吞吐与满仓，制作人批准该最小尺寸，不新增非必要倒角。

## 真实慢节奏试玩暴露的砖角问题

制作人两次真实触屏在静置10秒后沿同一正常解行进，第5步误判jam。金子被压在右邻砖角（例如中心约65.85/586.88），其本列左下方有空位；旧施力因左边是墙始终向右，反而将颗粒顶在右邻砖角。不能把此例称为真实封闭夹腔，也不能用改回窄口隐藏它。

针对性修正：仅在下落砖挤压时，检查直下及左右各2px、下方4px的局部实体可行性；直下畅通则不额外横推，否则向阻挡较少的一侧施加原有滚动力。仍由物理更新坐标，不直接移动或删除金子。制作人批准该修正；新增最小砖角和“等待10秒、每步思考.25秒”的两项回归先红后绿。
