# A/B 连续配重通关体验版

## 已授权范围

新增独立入口 `king-match/continuous/`，保留现有单关游戏。复用现有本地素材，不引入外部服务、远程数据或持久存档。

A、B 各有独立的三消盘、有限石料、真实接触压力、HP、配重斗、升降门和到达判定。每段只有一个消除区。石料堆在盾左侧，压力使国王向右后退并接触闭门危险面扣血；底部消除产生实际开口，石头落入斗内才增加配重。配重重于门与阻力后驱动同程升降，到顶锁止。门开不判胜；按“前进”沿实体地面走到本段出口才完成。

A 的出口通过上层连廊和带导轨的自动入场升降台连接 B 的防守位置，镜头跟随同一国王。B 到位后显示开始按钮，不在画外自动扣血。B 必须独立收集自身配重并到达终点，A 的配重、门和盘面不能通关 B。段间重置到100HP并明确提示；当前段重来保留A完成状态；刷新回A。

本原型采用有限初始库存，使重量守恒可验证，并避免持续供料无限刷重。物理为小游戏二维颗粒接触近似，不作工程散料仿真。三消为交换三连、现有宝石重力下落、不补新宝石；提示只找合法消除。开始前可观察；暂停和后台冻结模拟。开门后的前进由玩家点击，沿预定地面自动行走。

## 实施顺序

1. 写状态隔离、压力/配重因果、胜负与冻结测试，确认新模块缺失时失败。
2. 实现4×4三消、独立段落物理与机关。校准正常输入可开门、无操作有实际失败路径。
3. 实现连续世界、长廊、同一人物行走与相机。
4. 复用国王、盾、金矿、宝石和城堡素材，制作响应式界面、暂停/重来/提示/前进。
5. 桌面与模拟触控真实输入验证，三个评审分别打分，不通过则修复复审。
