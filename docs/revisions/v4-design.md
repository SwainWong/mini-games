# 国王消消乐 v4 设计

本次按架构修改执行：用户要求取代 v3 排石配额胜利，改全清宝石；修实体穿插，生成完整国王动画，新增低血受刺概率爆发。负责人仍为同一制作人，免费资源、零删除、批准后既有 Pages 发布。

## 方案

1. 几何统一：新增 geometry.js，共享厚斜坡四边形、砖块/石台矩形。圆与凸实体最短外法线投影；先解析整个砖集合的联合可行空间，避免相邻砖依次推出又推进。动态砖按真实 y 参与碰撞，下降量受下方颗粒支撑约束，挤压转为横向滚出；持续3.5秒累计下落不足0.5px视为堵塞，保留实体并显示通道堵塞/重来，不瞬移或删除颗粒；全场检测粒子-实体最大穿透。石头纹理限制在对应碰撞圆内，不能靠抹去碰撞范围之外的实体来假修。
2. 胜利：操作完全结算后 remainingColored===0 且 HP>0 即获胜。移除排石数量及安全计时胜利门槛，HUD显示剩余宝石与消除进度；排出计数仅只读诊断。固定石台是地形，不计宝石。
3. 关图：两关改为有明确全清解的有限三消棋盘；无初始三连、不补新宝石、保留重力连锁。以互锁三连/四连构造可解起盘，再用全清求解器核验，不把开排流通道当全清。选择错误可能让残局无法完成，重排只在求得全清解后提交和扣次数，搜索未找到保留盘面/次数并提示可重试或重来，不能宣称数学无解。
4. 人物：image 生成一张八格完整姿态动画图集，四帧完整退步/支撑循环、站稳、受伤、蓄力与推盾。统一角色、脚底和手部锚点，整帧播放；禁止现有切成左右方块的腿部演出。静止/暂停不循环步态，爆发单独姿态和暖金脉冲。
5. 高能：每次真实有效扣血后，若仍存活且 HP<=40，独立35%概率触发；持续2.2秒，从激活起冷却8秒，每局最多2次，不叠加、不回血、不免伤。使用与石料独立的随机源；正常全清必须无需好运。高能提高推盾实际力与前进速度上限，盾移动与颗粒碰撞同步，把近处金子推开，不瞬移粒子、不消砖。页面说明概率与触发条件。

## 对比与选择

不采用增加碰撞迭代却保留薄线边界的表面补丁；不通过把金子画在砖下面掩盖穿插；不使用几何切腿补间。全清优先纯三消，不引入自动删除残余砖或爆发代清砖。爆发为短暂脱险机会，不能成为固定脚本必胜。

## 验收

- 用户图1/2对应密集静止、动态下落、落稳和推盾均测实体穿透；同一几何用于渲染与碰撞。截图与数值共同验收。
- 大量排石但仍有砖不能胜，最后一砖经合法三消/连锁消除才胜，HP0同帧优先失败；两关真实输入全清可胜。
- 重排成功有全清 witness，失败不扣次数不改变砖位；1–2块残局明确不自动消除。
- image 原图保留，完整步态多帧、受伤/高能可观察，人物无矩形断腿。
- 概率触发和未触发、冷却/次数上限、暂停/重置均测试。观察高能前推和真实金子位移，不能靠治疗维持。
- 制作人重新独立试玩并评分，不继承 v3 的通过结论；发布后精确构建/文件hash/线上玩法分别核验。
