# 国王消消乐 v4 验证

本记录仅属于本次 v4，不继承 v3 的批准。制作人独立试玩与最终评分见 `v4-review.md`。开发证据在忽略的 `output/v4/` 与 `output/playwright/`，不发布用户参考图或本机路径。

## 实现

- 统一斜坡厚度与端盖实体/绘制，金子贴图的可见范围限制在其圆形碰撞体内。砖块、盾牌移动后再次约束；没有用绘制遮挡掩盖重叠。
- 新压力测试找到原投影将夹住颗粒单步挪动62.44px的问题。改为每块砖独立下落、仅受实际下方砖/颗粒支撑暂缓下降、挤压向侧面滚出；封闭堵塞有明确终止和重来，不删除粒子或强投到另一侧。
- 全清56/52颗宝石且HP>0即胜；第二关4格固定石台除外。尾盘、搜索限额失败和重排次数均明确处理。
- image生成并保留八格完整国王原图；全部身体整帧播放，统一比例与手脚锚点。无切割左右腿。
- 实际低血受刺后35%概率高能2.2秒，8秒冷却、每局最多2次。独立随机源；真实推盾，不回血/无敌/代消砖。
