# v8 验证记录

## 变更

- image 生成单手撑盾、背肩撑盾、受刺、收盾观察四组全身 PNG 动作；运行时不拆手脚，完整帧采用统一比例。
- 持续安全时收盾叉腰，预测近处来料时重新举盾；可见盾与碰撞体同步，完全收起后没有隐形挡墙。
- 移除广域前景集金槽。只有直接承受上砖压力、具有真实下砖承重链、持续没有净下落且无自然可接收脱困路线的金子局部碎裂。正常出口排出与夹碎分别守恒计数。
- 重砖向圆形颗粒的真实接触法线传力；纯侧面切线不再成为虚假垂直支点。已有净进展的慢流与离开落砖区域的金子立即释放辅助引导。
- 内部落稳期间国王安全等待，铰接挡板连续转动缓流，上仓照常补入。无空间时挡板暂停推进，不能扫穿颗粒；完成后连续开闸。
- 保留 v7：下落和连锁完成后，无有效三消交换的残局自动通关。
