# 独立视觉试玩 Round 1

评审日期：2026-09-17。线上地址：https://swainwong.github.io/mini-games/sand-marbles/?v=3 。独立浏览器 session：player-visual。

## 预先固定的评分标准（每项20分，总分100）

1. 视觉风格与完成度：沙土、珠子、罐子、人物、环境是否协调且精致，是否存在廉价占位感。
2. 字体、对比与信息层级：重要文字能否轻松读清，目标、机制、进度、反馈是否一眼可辨。
3. 桌面与手机构图：1440×900 和 390×844 下画布、操作区、弹窗是否完整实用，无遮挡、挤压和不必要的滚动。
4. 动态演出与反馈：挖沙、珠子运动、进罐、人物搬罐、通关演出是否连续、明确、有质感。
5. 关卡视觉变化与辨识：第1、第3和后期关的布局/机制/色彩是否形成变化，并保持可读性。

18–20：优秀，只有轻微问题；15–17：扎实但有可见欠缺；12–14：功能足够但明显不精致/影响体验；8–11：多项明显问题；0–7：严重影响使用。禁止为达90放宽标准。

## 操作与证据

- 使用真实 Chromium 可视浏览器，1440×900 桌面与390×844手机宽度。手机证据为响应式窄窗口、鼠标拖动，不声称物理手机触摸验收。
- 不读取游戏实现、不读取解法fixture、不写state；仅通过关卡选择按钮与真实鼠标按下/拖动/抬起试玩。只读 `window.sandGame.snapshot()` 对照结果及DOM字体尺寸。
- 第1关：滚动使整个画布可见；从珠池向右下罐口划一条斜线。6/6，挖沙230，3星，游戏时间2秒。
- 第3关：在关卡弹窗选择第3关；左池向中央罐口、右池绕过右下石头接至中央罐口，各挖一条路。11/11，挖沙344，3星，游戏时间10.4秒；接珠盘等待11颗，小人搬罐一趟后入罐。
- 第15关：在390×844关卡弹窗选择第15关；先挖底部两池，再连接中层两池，顶部琥珀/玫瑰色珠分别绕外侧向对应罐引流。30/30，挖沙608，3星，游戏时间46.4秒，搬罐4趟，蚯蚓挖沙1630格。未使用自动解法。
- 截图目录：`output/reviews/player-visual/`。`desktop-1440x900-top.png` 为桌面原始首屏；`desktop-level1-dug.png`、`desktop-level1-win.png` 为挖沙与胜利；`desktop-level3-start.png`、`desktop-level3-play.png`、`desktop-level3-win.png` 为搬运工与暂存演出；`mobile-level-menu.png` 为选关；`mobile-level15-start.png`、`mobile-level15-play.png`、`mobile-level15-routes.png`、`mobile-level15-win.png` 为后期手机布局与实玩结果。

## 问题与可复测验收

### P2 V1：关键功能文字过小

证据：390宽实测机制标签8px、三星预算8px、画布提示8px、铲子按钮9px、底部搬罐状态9px；见 `mobile-level15-start.png`、`mobile-level15-routes.png`。首屏整体像被压缩的桌面界面，字体需要刻意盯着看。

验收：390宽和桌面下机制/预算/动态状态/画布提示等操作所需内容至少12px，主要按钮文字至少12px；文字颜色能够不放大读清。重新通关第3/15关，验证提示加大后不遮珠、不压窄画布、不溢出。

### P2 V2：桌面首屏不能完整容纳游戏

证据：1440×900、scrollY=0时canvas顶部343px、底部942.84px，反馈还在更下方；见 `desktop-1440x900-top.png`。游戏宽442px但页面两侧大量空白，纵向却容不下。

验收：1440×900进入即可同时看到关卡、基本工具、完整画布/罐子、重要反馈与重来；可精简上方装饰、横向放置辅助内容或提供直接进入游戏的紧凑布局。不得仅缩小所有文字来达标。手机允许合理滚动但玩法中不要来回寻找核心控制。

### P2 V3：手机选关五列导致关名难辨

证据：`mobile-level-menu.png`，每列约55px，标题“斜坡初体验”等呈微小文字，数字远比关名清楚。

验收：390宽弹窗关名≥12px，推荐3列或纵向关卡列表，允许弹窗内部滚动；关闭键保持可见，1/3/15关均可正常选择，无文字截断或相邻关误辨。

### P3 V4：铲子按钮与次要操作显得过于微型

证据：390宽“精细/常规/宽铲”为38×25px，“玩法说明”为54.8×25px；选中状态主要是微弱底色和细边框。

验收：常用按钮实际可点区域高度≥40px，选中铲子有不只靠细微色差的明确状态；窄屏单行或换行排版整齐。

### P3 V5：物性和暂存语义依赖小标签

证据：后期四种物性的珠子很小，手机画面肉眼首先只能区分颜色；第3关固定盘上的“暂存”文字尺寸更小，小人在搬罐时需读上方提示才能快速理解。

验收：珠子物性增加能在手机画面辨认的稳定标志/纹理，或提供清晰而紧凑的图例；暂存盘有清楚的数量徽标/视觉引导，罐子搬走时能立即理解珠子会被安全保存。无需加长说明。

## 复测范围与边界

复测必须沿用以上五项标准。字体、选关及构图改进最可能明显提升当前评分；美术与演出仍按实际看到的结果独立评价，不预承诺90分。已验证第1/3/15关的真实操作通关，但不据此声称全部15关、物理手机触摸、声音或浏览器兼容性验收完成。
