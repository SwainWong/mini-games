# v11：过关门槛与一局结束分离

用户修订：达到最低分后继续争取分数，不能立即终止，避免所有过关成绩被截成同一个数字。

## 规则

1. **达到门槛**：显示“已达标，继续冲分”，继续物理、机关、盗宝人和加分。此时尚未结算，也没有星级。
2. **关卡时间耗尽**：最终分数达到门槛则通关，否则失败。最后物理步只推进剩余时间，该步有效入车/宝物事件全部处理完再结算，不吞掉截止前得分。
3. **剩余机会不足**：已有分数 + 剩余珠子与宝物的理论最高可得 < 门槛，则提前失败。达标后因为分数不倒扣，后续被偷/漏接不再使已有合格成绩变成失败。
4. **珠子全部结算**：提前按最终分数结束，不要求玩家空等倒计时。珠子可由入车、错色、漏接、被偷结算；未被珠子打开的宝物不能自动兑分。

第一关门槛40，最终可以是40、50或60分。星级仍只在通关后按最终挖沙量评定；为了冲更多分而挖更多沙，可能影响星级。关卡选择与结算显示本次页面最高分，刷新清空。

## 时限

|关卡|时限（秒）|
|---|---:|
|1—2|45|
|3—5|50|
|6—7|55|
|8—10|60|
|11—12|65|
|13—14|70|
|15|75|

HUD显示剩余时间，最后10秒变色。首次图鉴、普通图鉴、选关或后台均暂停计时；恢复不补跑，重新挑战重置时限。不设保存、上传、排行榜或额外数据服务。

## 验证

`node --test sand-marbles/tests/*.test.cjs`：91项通过，包含十五关四种子和炸药可选/点火路线。

新增7项回归覆盖：达标不终止、继续拿到更高分、时间到的胜败、机会不足提前结束、达标后损失不反判、截止前后接珠、最终物理步的事件全部计分。旧盗宝人“不会按时间偷珠”测试现在区分正常关卡超时与实际偷珠，超时不能凭空增加被偷数量。

`browser-round-end.js`使用真实CDP触摸挖沙、只读采样与真实等待：记录40分仍playing且0星，继续加分后以exhausted结束；检查45秒无操作超时失败、图鉴暂停、重来时限恢复、最高分刷新归零、360×800同屏布局。脚本不修改世界、时间或得分。

实际回放第一关达到40分时继续运行，最终60分结算；无操作45秒超时失败。桌面鼠标与移动端触摸边缘接珠另行复测，分别取得60/50分，外沿漏接、失败定格、重开与刷新通过，页面无JavaScript错误。
