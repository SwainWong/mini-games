# 矿车车沿修复（随 v10 发布）

v9是本地边界修复阶段编号，未单独发布；最终合并进积分矿场v10。

旧版绘制车斗内半宽46，但物理又减去珠子半径8—10，使看起来在开口内的珠子被漏判。漏接还等珠子掉到y620以后才结算，移动矿车继续走动，失败画面与实际判定时刻不一致。

现在共享 `CART_MOUTH` 可见几何，珠子中心下降跨越y590时判断±46，以珠子与矿车相对运动求接触时间。可见开口内部接住；外部在车口高度记为漏接。只有积分机会不足才失败，并把矿车/珠子冻结在同一接触时刻。错误颜色仍为0分，不直接判负。

`cart-edge.test.cjs`覆盖4材质、两沿、移动方向、480速度/偏移组合；真实鼠标与手机触摸曾复现旧版内沿误判，最终v10同一路线正常达到目标。详细结果在[发布记录](reviews/sand-score-release.md)。
